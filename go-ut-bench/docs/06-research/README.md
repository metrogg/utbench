# 研究资料

本目录是统一文档树中的研究入口。研究材料已经并入当前目录，外层旧目录不再作为阅读入口。

## 使用规则

- 这些文档用于理解背景、路线和方法论。
- 它们不是当前实现的行为依据。
- 如与当前代码或主文档冲突，以 `go-ut-bench/` 下代码和主文档为准。

### 仓库级数据集设计讨论
- 用户提出要设计仓库级(repository_level)数据集

  1. 扩展meta.json为5维度样本契约(source/target/context/environment/evaluation)
  2. 标准化目录结构(repo_snapshot + meta.json + .context/)
  3. 新增DatasetClassRepositoryLevel常量
  4. Runner增加环境准备步骤，Evaluator增加构建检查和回归测试
  5. 候选仓库：django/requests/flask(go) gin/zap(java) guava/spring(cpp) abseil
  6. 推进顺序：schema设计 → 手工制作20-30个MVP样本 → 代码适配 → evaluator适配 → 扩充
- 等待用户反馈：样本来源(开源vs内部)、难度标注维度、上下文控制模式、MVP优先语言和仓库

### Agent评测生态调研
- 完成全面的Agent评测生态开源项目调研
- 输出报告：AGENT_BENCHMARK_SURVEY.md
- 关键发现：

  2. 单元测试生成方向仅~7篇论文，UT-Bench处于蓝海
  3. 极简主义趋势（mini-swe-agent 100行代码score 74%）
